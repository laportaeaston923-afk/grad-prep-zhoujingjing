# 论文名称

**Echo-Conditioned Denoising Diffusion Probabilistic Models for Multi-Target Tracking in RF Sensing**

方法名称：**Echo-Conditioned C-DDPM（回波条件扩散模型）**

## 1. 核心内容

这篇论文主要研究：**如何利用 RF（射频）回波信号和扩散模型，在动态环境中持续预测和跟踪多个目标的位置，从而提高无线感知系统的跟踪精度。**

在无线感知系统中，基站向环境发射感知信号，信号遇到人体、车辆、无人机等目标后产生反射回波。基站通过分析这些回波，可以估计目标的位置和运动情况。

但是在动态环境中，目标的位置、运动方向和反射特性会不断变化，同时回波中还存在噪声、多径和杂波，导致准确跟踪多个目标比较困难。

为了解决这个问题，论文提出了一种基于**条件去噪扩散概率模型（Conditional DDPM，C-DDPM）**的多目标跟踪框架。

**整体过程：**

RF Echo → VAE 特征压缩 → Conditional DDPM → 预测下一时刻目标状态 → 调整感知波束 → 下一轮 RF Sensing

其中：

- **RF Echo：** 基站接收到的目标反射信号，包含目标方向、距离、运动和反射特性等信息。
- **VAE：** 将高维回波信号压缩成低维特征，作为扩散模型的条件输入。
- **C-DDPM：** 根据回波特征，预测下一个时间块中多个目标的角度和距离。
- **Beam Selection：** 根据预测结果选择合适的感知波束，提高下一次感知的准确性。

论文的目标不是生成图像，而是**预测多个目标未来的空间状态，并利用预测结果指导后续感知。**

## 2. 已有方法有什么问题？

已有的 RF 目标定位和跟踪方法主要包括**传统信号处理方法、滤波方法和深度学习方法**。

### （1）传统信号处理方法

典型方法包括：

- MUSIC
- ESPRIT

这类方法主要利用接收信号的空间特征估计目标方向，例如 AoA（到达角）。

**缺点：**

- 当信噪比（SNR）较低时，估计精度容易下降。
- 在采样数量有限、多径传播或者强杂波环境下，容易产生较大的估计误差。
- 主要关注当前观测信号的参数估计，不能直接解决动态场景中的未来状态预测问题。

### （2）传统滤波方法

典型方法如 Kalman Filter（卡尔曼滤波）。

这类方法通常利用目标的历史状态和预先设定的运动模型，预测目标下一时刻的位置，再通过新的观测不断修正预测结果。

**缺点：**

- 通常需要对目标运动规律和噪声分布作出一定假设。
- 当目标突然转向、速度发生变化或者环境比较复杂时，预设运动模型可能不准确。
- 当缺少可靠观测修正时，预测误差可能逐渐累积。

### （3）深度学习方法

典型方法是 CNN Regression。

**RF Echo → CNN → 目标角度和距离**

这类方法直接学习回波信号与目标状态之间的映射关系。

**缺点：**

- 通常需要大量带标签的数据进行训练。
- 普通回归模型主要学习确定性的输入输出映射，难以充分描述目标运动的不确定性。
- 当测试场景中的目标运动规律发生变化时，模型可能泛化较差，并出现预测误差累积。

因此，论文希望使用扩散模型学习**在给定噪声回波观测条件下，未来目标状态的概率分布**，而不是只学习一个固定的回归结果。

## 3. 核心思想

论文的核心思想是：

**先用 VAE 提取回波中的低维特征，再将这些特征作为条件输入 C-DDPM，通过扩散生成预测下一时间块的目标角度和距离，最后根据预测结果选择感知波束。**

整体结构：

**RF Echo → VAE → Condition → C-DDPM → Target States → Beam Selection**

具体来说：

- **VAE：** 对高维 RF 回波信号进行压缩，得到能够表示回波主要信息的低维 Latent。
- **Conditional DDPM：** 将 VAE 提取的特征作为条件，从随机噪声开始逐步去噪，生成下一时间块的目标状态。
- **Classifier-Free Guidance（CFG）：** 同时利用有条件和无条件的噪声预测，增强生成结果与回波条件的一致性。
- **Beam Selection：** 利用预测的角度和距离，计算候选感知波束的得分，选择适合下一次探测的波束。

这里需要注意：

**VAE 并不是把目标状态压缩之后交给 DDPM。**

它压缩的是接收到的高维回波信号。

DDPM 生成的则是多个目标的状态向量。

两者的关系是：

- VAE：提取条件信息。
- DDPM：根据条件生成未来目标状态。
- Beam Selection：利用预测结果改善下一次感知。

因此，这篇论文虽然同时使用 VAE 和 DDPM，但它不是 LatentCSI 那种在图像潜在空间中进行扩散的 LDM 框架。

## 4. 整体框架

论文的整体流程可以结合 **Fig. 1、Section IV 和 Algorithm 1** 理解。

需要注意，Fig. 1 主要展示 RF 感知系统的工作场景，而不是神经网络结构图。完整算法流程主要由 Section IV 和 Algorithm 1 给出。

### （1）RF Sensing：回波信号采集（Fig. 1）

论文考虑一个配备多根发射天线和接收天线的基站。

基站向环境发射感知波束，波束遇到不同目标和杂波后产生反射信号，再由基站接收。

系统将时间划分为多个 Block，每个 Block 包含多个 Symbol。

**整体过程：**

Block l：发射感知信号 → 接收 RF Echo → 预测目标在 Block l+1 的状态

Block l+1：使用更新后的感知波束 → 接收新的 RF Echo → 继续预测

其中：

- **Symbol：** 一个感知信号的符号时隙。
- **Block：** 一组连续的感知符号，用于收集当前时间段的回波。
- **目标状态：** 主要包括目标相对于基站的角度 θ 和距离 d。

论文假设目标状态在一个 Block 内基本保持不变，而在不同 Block 之间发生变化。

实验中，每个 Block 包含 **64 个 Symbol**。

因此，一个 Block 并不是 64 个不同的目标位置，而是通过 64 次符号观测，收集当前场景的回波信息。

### （2）VAE：回波特征压缩

接收到的 RF Echo 是一个高维复数矩阵，其中包含实部和虚部。

如果直接把整个回波矩阵输入 DDPM，条件输入维度较高，不利于高效建模。

因此，论文引入 VAE，对回波进行特征压缩。

**RF Echo → 实部/虚部分离 → RMS 归一化 → VAE Encoder → Latent z**

具体过程：

**第一步：回波预处理**

将复数形式的接收回波划分为实部和虚部，形成两个通道，并进行 RMS 归一化。

**第二步：VAE Encoder**

将归一化后的回波输入 VAE，得到低维潜在表示 z。

论文实际使用 VAE 编码器输出的后验均值作为条件特征。

**第三步：提取回波能量**

由于 RMS 归一化会消除回波的绝对幅度信息，论文额外计算一个回波能量特征 E。

**第四步：构建条件向量**

将 VAE 提取的 Latent 和能量特征拼接：

**Condition = [z, E]**

然后进一步进行 EMA 统计归一化，形成最终的条件向量 c。

其中，VAE 的 Latent 维度为 **128**，再加上一个能量特征，因此原始条件向量维度为 **129**。

VAE 的作用是保留重要的回波信息，并降低扩散模型接收条件信息的复杂度。

### （3）C-DDPM：下一时间块目标状态预测

这是论文最核心的部分。

C-DDPM 并不是直接预测下一次的 RF Echo，而是预测**下一时间块多个目标的角度和距离**。

论文首先构造目标状态向量：

\[
x_l=[\sin\theta_l,\cos\theta_l,\rho(d_l)]
\]

其中：

- θ：目标相对于基站的方向角。
- d：目标到基站的距离。
- ρ(d)：对距离进行对数归一化。
- Q：目标数量。

每个目标使用三个数值表示，因此状态向量的总维度为 **3Q**。

例如，当环境中有 9 个目标时，状态向量维度就是 27。

这里使用 sinθ 和 cosθ，而不是直接使用角度数值，是为了更好地处理角度的周期性。

**训练阶段**

训练时，模型学习当前回波条件与下一 Block 真实目标状态之间的关系。

两部分输入分别为：

- **Condition c_l：** 当前 Block 的回波经过 VAE 处理后得到的条件特征。
- **Target x_{l+1}：** 下一 Block 的真实目标状态向量。

对于真实状态 x_{l+1}，随机选择扩散时间步 t，并向其加入高斯噪声：

\[
x_t=\sqrt{\bar{\alpha}_t}x_{l+1}+
\sqrt{1-\bar{\alpha}_t}\epsilon
\]

然后让 C-DDPM 的去噪网络预测所加入的噪声：

\[
Loss=\|\epsilon-\epsilon_\psi(x_t,t,c_l)\|^2
\]

通过不断训练，模型学习：

**当前 Block 的回波特征 → 下一 Block 目标状态的条件概率分布**

论文还采用 Classifier-Free Guidance：

训练时以一定概率丢弃条件输入，让模型同时学习有条件和无条件的噪声预测。

推理时将两种预测组合，从而增强生成结果对当前回波的依赖。

**推理阶段**

推理阶段不再需要下一 Block 的真实目标状态作为输入。

**Condition c_l + Gaussian Noise → C-DDPM 迭代去噪 → 预测状态 x̂_{l+1}**

具体过程：

1. 使用当前 Block 的回波提取条件向量 c_l。
2. 从随机高斯噪声开始采样。
3. 在每一步去噪中引入 c_l。
4. 经过多步反向扩散，得到预测的目标状态。
5. 将状态向量还原为每个目标的角度和距离。

实验中：

- **Diffusion Steps：200**
- **采样数量 K：128**
- **CFG Guidance 参数 w：3**
- **Condition Dropout 概率：0.05**

其中，K=128 表示在一次状态预测中，从扩散模型采样得到 128 组可能的下一 Block 目标状态。

不是生成 128 个连续时间块，也不是预测未来 128 个时间点。

使用多个样本的原因是：未来目标位置具有不确定性，单个预测结果可能无法充分描述可能出现的运动情况。

另外，论文采用 **U-Net-based Denoising Network** 作为 DDPM 的去噪骨干网络。

### （4）Beam Selection：根据预测结果选择波束

这一步是论文与普通目标位置预测方法不同的地方。

如果只是预测下一时刻目标的位置，整个过程仍然是单纯的目标跟踪。

但本文进一步利用预测结果，调整下一次 RF Sensing 使用的感知波束。

**目标状态预测 → 计算候选波束得分 → 选择最优波束 → 下一 Block 感知**

具体过程：

**第一步：生成多个预测结果**

C-DDPM 生成 K=128 组下一 Block 的目标角度和距离预测。

**第二步：计算波束得分**

对于每个候选波束，计算它与预测目标方向之间的阵列增益，并引入距离相关权重，以减轻传播损耗导致的近距离目标偏置。

**第三步：对多个预测结果求平均**

对 K 组预测结果得到的波束得分进行平均，从而考虑未来目标状态的不确定性。

**第四步：选择波束**

从候选波束码本中，选择得分最高的若干个波束，用于下一 Block 的感知。

实验中：

- 候选码本：32 个 DFT 波束。
- 每个 Block 选择：8 个感知波束。
- 对选中的波束采用等功率分配。

这样就构成了一个循环：

**当前回波 → 预测下一状态 → 选择下一波束 → 获取新的回波 → 继续预测**

其目的不仅是提高当前目标状态估计的准确性，也是让之后的感知更加有效。

### （5）整体训练与推理过程（Algorithm 1）

论文将整个实验划分为前期训练和后期推理两个阶段。

训练阶段：

**RF Echo → VAE → Condition → C-DDPM 训练 → 下一 Block 状态预测**

前期通过仿真环境提供真实目标状态，训练 DDPM 学习回波与下一 Block 状态之间的对应关系。

VAE 使用重建项和 KL 散度构成的 ELBO 目标进行更新。

DDPM 使用噪声预测损失训练，并通过 Replay Buffer 保存训练样本。

推理阶段：

**RF Echo → VAE → Condition → C-DDPM 采样 → 预测位置 → Beam Selection**

模型不再使用真实目标状态进行 DDPM 参数更新，而是根据当前回波预测下一 Block 的角度和距离，并据此选择下一组感知波束。

实验中总共设置 **5000 个 Block**：

- 前 400 个 Block 用于 DDPM 训练。
- 后 4600 个 Block 用于推理与性能评估。

需要注意，Algorithm 1 中 VAE 的 ELBO 更新仍位于逐 Block 循环内，并没有明确在第 400 个 Block 后停止。因此，不能简单地理解为训练阶段结束后所有网络参数都完全冻结。

## 5. 总结

这篇论文提出了一种基于 **VAE + Conditional DDPM + Beam Selection** 的多目标 RF 感知跟踪框架。

它首先利用 VAE 将高维回波信号压缩为低维条件特征，再利用条件 DDPM 学习回波特征与未来目标状态之间的概率关系，通过迭代去噪生成下一时间块的角度和距离预测。

在此基础上，论文根据多个预测结果计算候选波束的期望增益，选择下一轮感知所使用的波束，从而形成预测与感知相互配合的过程。

相比传统的 MUSIC、ESPRIT、CNN 和 Kalman Filter，该框架在仿真环境中具有更低的角度和距离跟踪误差，并表现出更好的动态场景适应能力。

**核心创新：将 RF 回波特征作为条件输入扩散模型，通过概率生成方式预测多个目标的未来状态，并进一步利用预测结果自适应选择感知波束，实现面向动态环境的多目标跟踪。**
