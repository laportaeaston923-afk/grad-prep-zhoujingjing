# 论文名称

**Diffusion Model-Based Contrastive Learning for Human Activity Recognition（CLAR）**

- **作者：** Chunjing Xiao、Yanhui Han、Wei Yang、Yane Hou、Fangzhan Shi、Kevin Chetty
- **出处：** *IEEE Internet of Things Journal*, 11(20), 33525–33536, 2024
- **论文：** [IEEE Xplore / DOI](https://doi.org/10.1109/JIOT.2024.3429245) · [arXiv:2408.05567](https://arxiv.org/abs/2408.05567) · [开放版本（UCL）](https://discovery.ucl.ac.uk/id/eprint/10194462/)
- **官方代码：** [ChunjingXiao/CLAR](https://github.com/ChunjingXiao/CLAR)
- **方法关键词：** WiFi CSI、人体活动识别、DDPM 数据增强、对比学习、DTW、自适应权重

## 1. 核心内容

CLAR 主要解决 WiFi CSI 人体活动识别中的两个问题：

1. **数据多样性不足：** 使用 DDPM 进行数据增强，生成更丰富的 CSI 数据。
2. **不同正样本包含的有效动作信息不同：** 利用 DTW 分析样本的动作信息，并通过 Adaptive Weight 调整不同正样本的权重。

最终目的是学习更有效的 CSI 特征，提高人体活动识别效果。

## 2. 已有方法有什么问题？

- **传统数据增强：** 生成的样本容易与原始 CSI 过于相似，难以充分增加数据多样性。
- **普通对比学习：** 不同正样本往往被类似地处理，但人体动作包含起始、停顿和结束阶段，各片段所包含的有效动作信息并不相同。

因此，仅增加样本数量还不够，还需要考虑**生成数据的多样性**和**正样本的有效信息差异**。

## 3. 核心思想

- **DDPM：** 解决“数据不够多样”的问题。
- **DTW + Adaptive Weight：** 解决“不同正样本重要程度不同”的问题。
- **Contrastive Learning：** 利用增强数据和加权目标学习更好的 CSI 表示。

**DDPM 数据增强 → DTW 评估有效信息 → 自适应加权对比学习 → 人体活动识别**

## 4. 整体框架

### （1）总体流程

整个 CLAR 可以理解为：

原始 CSI
↓
DDPM 数据增强
↓
得到更多 CSI 样本
↓
CSI 特征提取
+
DTW 计算样本有效信息
↓
得到 Adaptive Weight
↓
加入对比学习损失函数
↓
优化 CSI 特征
↓
人体活动识别


### （2）为什么使用 DDPM

解决 CSI 数据多样性不足的问题

传统数据增强一般是在原始数据上进行简单变换，这种方法虽然可以增加数据数量，但是生成的数据和原始数据比较相似。

DDPM 可以通过学习 CSI 数据的分布，从噪声中生成新的 CSI 样本，因此能够产生更加多样的数据。

所以这里 DDPM 的主要作用不是进行分类，而是：数据增强。


### （3）Source 和 Reference 的作用

论文不是让 DDPM 完全随机地生成 CSI，而是引入 Source 和 Reference 作为条件信息。

Source 更像是生成的基础，

Reference 提供希望生成的动作相关信息。

因此生成的数据既不是完全复制原始 CSI，也不是完全随机生成，而是在参考动作特征的基础上生成新的 CSI。


### （4）高频和低频分解

Reference 中包含不同尺度的信息。

低频信息可以理解成动作的整体变化趋势，
高频信息可以理解成更加细节的变化。

因此作者不是直接把完整的 Reference 一次性加入 DDPM，而是：

低频
↓
先确定整体结构

高频
↓
再补充细节

先整体再局部，如果在扩散过程早期直接加入变化比较剧烈的 CSI 信息，可能会破坏原来的噪声分布，从而造成生成数据失真。


### （5）Adaptive Weight

传统对比学习中，不同正样本通常被比较类似地处理。

但是对于人体动作来说：

一个完整动作中可能存在停顿、起始阶段、结束阶段等。

因此不同位置裁剪出来的 CSI 片段包含的有效动作信息并不一样。

例如论文“画 X”：因为动作过程中可能存在暂停，所以不同位置裁剪出来的正样本对，包含的动作信息是不一样的。
比如 \(x_1,x_2\) 包含较多暂停数据，而 \(x_3,x_4\) 包含更多真实动作数据。
因此，\(x_3,x_4\) 对学习动作特征更重要，应该赋予更大的权重。

论文利用 DTW 对样本进行分析，最终得到 Adaptive Weight，并将其加入对比学习损失。


### （6）实验部分

#### 实验目的

论文实验主要想证明几个问题：

1. CLAR 整体是否能够提高人体活动识别性能？
2. DDPM 数据增强是否真的有效？
3. Adaptive Weight 是否真的有效？
4. 在少量标注数据的情况下，CLAR 是否仍然能够保持较好的性能？


#### 数据集

SignFi
DeepSeg

#### 总体性能对比
1.对比ManiGAN、CsiGAN、RF-Net、MetaAct、MultiSSL、SimCLR、AutoFi、CLAR。
2.结论:CLAR 在 SignFi 和 DeepSeg 上都取得更好的结果.

#### 消融实验
1.实验分组设计
  CLAR-Base：基础对比学习基准框架
  CLAR-Aug：仅引入DDPM数据增强模块
  CLAR-Weight：仅加入自适应权重机制
  CLAR-Full：整合双模块的完整框架
2.结论：DDPM增强与自适应权重均可独立提升性能；二者结合后达到最优指标，证明了组件间的互补性与协同增益，验证了框架设计的合理性。

#### 数据增强模型的普适性
1.选取MetaAct、CDFi、MetaFormer等主流WiFi HAR基线模型，将CLAR生成的增强数据作为额外训练样本，对比模型在有无增强数据下的性能表现差异。
2.结论：所有基线模型性能均显著提升，证明CLAR的DDPM模块生成的数据具备高质量特征迁移能力，可作为通用工具打破单一模型的性能瓶颈，赋能各类WiFi感知模型。

#### 标记数据量的影响
1.改变有标签数据比例，同时设置不同的无标签数据比例。
2.结论：CLAR 可以利用大量无标签 CSI 数据，只需要少量标注数据就能够达到比较稳定的识别效果。


## 5. 总结与我的理解

这篇论文的 DDPM 主要用于**数据增强**，而不是直接完成动作分类。它通过 Source 和 Reference 提供生成参考，再利用 DTW 和 Adaptive Weight 处理正样本的有效信息差异，最终让对比学习得到更有用的 CSI 特征。

**我的理解：** 论文的两个关键模块解决的是不同问题：DDPM 扩展数据分布，Adaptive Weight 则帮助模型更合理地利用增强后的样本。
