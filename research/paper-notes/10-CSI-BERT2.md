# 论文名称

**CSI-BERT2: A BERT-inspired Framework for Efficient CSI Prediction and Classification in Wireless Communication and Sensing**

- **作者：** Zijian Zhao、Fanyi Meng、Zhonghao Lyu、Hang Li、Xiaoyang Li、Guangxu Zhu（通讯作者）
- **出处：** IEEE Transactions on Mobile Computing；2025 年在线发表，预印本首发于 2024 年；DOI：10.1109/TMC.2025.3640420
- **论文：** [IEEE / DOI](https://doi.org/10.1109/TMC.2025.3640420) · [arXiv](https://arxiv.org/abs/2412.06861) · [PDF](https://arxiv.org/pdf/2412.06861)
- **官方代码：** [RS2002/CSI-BERT2](https://github.com/RS2002/CSI-BERT2)
- **方法关键词：** BERT、CSI 恢复、MPM、ARL、时间嵌入、预训练与微调

## 1. 核心内容

CSI-BERT2 将 BERT 的掩码学习思路用于无线 CSI 序列，统一支持缺失数据恢复、未来信道预测和感知分类。它处理的是数值信号，不是把 CSI 翻译成文字。

**整体流程：** CSI 序列 → 标准化 → ARL 与线性映射 → 加入位置和时间嵌入 → BERT 主干 → 按任务选择数值输出头或分类输出头。

## 2. 已有方法有什么问题？

无线数据常出现丢包、标注不足和采样率变化。逐子载波插值容易忽略子载波之间的关联；自回归预测未来 CSI 会积累误差；为每个任务重新设计模型也增加成本。

作者通过先恢复掩码数据、再微调下游任务，让同一个框架利用有限数据学习时序表示。这里的预训练不等于必须先用海量跨领域数据训练基础大模型。

## 3. 核心思想与创新点

| 设计 | 解决的问题 |
|---|---|
| ARL 自适应重加权 | 区分不同子载波的信息价值 |
| MLP 时间嵌入 | 明确表达实际采集时间，辅助适应不规则采样 |
| MLM 预训练 | 随机遮挡数据，从可见 CSI 学习恢复 |
| MPM 未来预测 | 遮挡末尾片段，根据历史一次输出未来片段 |
| 分类微调 | 利用序列表示判断手势、动作、身份或人数 |

**两点区分：** 位置嵌入回答“第几个”，时间嵌入回答“何时采集”；MPM 一次预测末尾一段，不是把未来包逐个生成再作为下一步输入。预训练的 GAN 判别器属于训练辅助组件，不能把 CSI-BERT2 归为扩散模型。

## 4. 图表阅读与基础概念

### 与前作 CSI-BERT 的区别

<img width="203" height="251" alt="image" src="https://github.com/user-attachments/assets/302cab01-05aa-407f-a71f-fd3be8a20e7c" />

**MPM 是“怎么训练模型预测未来”，DANN 是一种“对抗学习方法”。两者负责的事情不同。**

**① MPM：Mask Prediction Model，掩码预测模型**

这是 CSI-BERT2 用来训练**未来 CSI 预测**的方法。

普通随机掩码恢复：

> 输入：A、？、C、？、E  
> 任务：根据前后信息，补出B、D。

MPM则**只遮住末尾一段**：

> 输入：A、B、C、？、？  
> 任务：根据前面的信号，预测后面的D、E。

这里A～E代表不同时刻的 CSI 数据包。

**所以，MPM主要改变的是遮挡位置和训练目标，不是另外增加一个网络模块。** 论文测试时用前0.8秒预测后0.2秒。

**② DANN：Domain-Adversarial Neural Network，域对抗神经网络**

它通常包含**特征提取网络和域判别器**：

- **判别器：** 尝试判断特征来自哪个数据域。

- **特征提取网络：** 学习让判别器难以区分来源的特征。

例如，判别器想分辨“这些特征来自房间A还是房间B”，特征提取网络则尝试保留两边共有的信息、减少环境差异。**这只是解释DANN机制的例子，不是说前作一定做了这个房间实验。**

实现这种“较劲”的关键是**梯度反转层**：反向传播时，把判别器传给特征提取网络的梯度反向。

在前作 CSI-BERT 中，作者采用了 **DANN式对抗训练**辅助信号恢复；CSI-BERT2将其改为 **GAN式训练**：判别器区分真实和恢复的 CSI，恢复器努力生成更真实的信号。

| **名称** | **在论文中的角色**       | **最简单的理解**                       |
|----------|--------------------------|----------------------------------------|
| **MPM**  | 第二篇的未来预测训练方法 | 遮住后面，让模型预测后面               |
| **DANN** | 前作采用的对抗学习方式   | 判别器努力区分，特征网络努力让它分不清 |
| **GAN**  | 第二篇采用的对抗学习方式 | 判别器辨真假，恢复器努力恢复得更像真的 |

CSI-BERT2 没有先做 Widar3.0 那种物理运动特征提取，而是把 CSI 序列交给网络学习。

CSI 通常包含幅度和相位；本文实现主要使用 CSI 幅度序列。

过程:发送端发出已知信号 → 信号经过环境传播 → 接收端收到信号 → 对比发送与接收信号 → 估计 CSI。

### Fig1：**一个数据包里包含多个子载波的 CSI 数值。** 连续采集很多个数据包，就得到一段随时间变化的 CSI。

**① Standardization Layer：**标准化，让变化更容易被比较

不同子载波的数值大小可能差别很大

<img width="600" alt="笔记配图" src="https://raw.githubusercontent.com/laportaeaston923-afk/grad-prep-zhoujingjing/49b47038efaecef76844ea666f59e390ff363ac1/research/paper-notes/assets/10-CSI-BERT2/media/image2.png" />

通俗来说：

- **减去均值：** 去掉这段信号的整体高低。

- **除以标准差：** 调整波动的尺度。

这样，上面 A、B 标准化后的变化模式就会相同，模型更容易发现它们具有相似的变化规律。

**这个模块是在调整数值，不是在识别人数，也不等于去掉所有噪声。**

**② ARL：给不同子载波分配“关注程度”**

**③ Linear Layer：**把一个数据包整理成一个特征向量

CSI 数值 → 线性层映射成向量 → Transformer

### Token 是什么？

一个词元 → 数字编号（Token ID）→ 数字向量（Token Embedding）→ Transformer

• **数字编号：** 像身份证号，用来查找对应的向量。

• **向量：** 一组数字，真正参与 Transformer 的计算。

文字例子：假设分词器把“我爱你”拆成三个 Token：

| **Token** | **数字编号 Token ID** | **查表得到的向量**      |
|-----------|-----------------------|-------------------------|
| 我        | 12                    | \[0.2, 0.5, −0.1, 0.8\] |
| 爱        | 35                    | \[0.7, −0.3, 0.4, 0.1\] |
| 你        | 68                    | \[−0.2, 0.6, 0.9, 0.3\] |

### 位置与时间编码

这部分是在给每个 CSI Token 加上“顺序和时间标记”，让 BERT 知道这些信号是按什么顺序、隔多久采集的。

**进入 BERT Backbone 之前**：把对应的三种向量相加。

例如，第1个 Token：

<img width="600" alt="笔记配图" src="https://raw.githubusercontent.com/laportaeaston923-afk/grad-prep-zhoujingjing/49b47038efaecef76844ea666f59e390ff363ac1/research/paper-notes/assets/10-CSI-BERT2/media/image3.png" />第2个 Token 同样加入自己的时间和位置向量，以此类推。

**所以，右侧两路编码最终加到左侧 Linear Layer 输出的每一个 Token 上，再一起送入 BERT。图中没有把每个 Token 的相加过程逐一画出来。**

左下从下到上第二个Linear Layer里写的 T_1、T_2、T_3，是**给读图的人看的编号**，不会自动变成向量中的信息。

数据虽然按顺序放进去了，但 **BERT 的自注意力本身不会自动把排列位置理解成“第几个”**，所以需要：

- **位置嵌入：** 告诉模型“这是第几个”。

- **时间嵌入：** 告诉模型“它对应什么采集时间”。

这样，顺序和时间才明确地进入模型计算。

### Fig. 2：三种任务的使用方式

图 1 讲内部结构，图 2 讲同一框架如何用于恢复、预测与分类。

**① 图2(a)：CSI Recovery——恢复信号，也是预训练任务**

流程是：

**随机遮住部分 CSI → CSI-BERT2 恢复 → 与原始信号比较。**

图中红色区域表示被遮住的数据。模型根据剩余信号，预测这些位置原本的 CSI。

旁边的 **Discriminator（判别器）** 负责区分真实 CSI 和恢复出的 CSI，推动模型生成更接近真实信号的结果。

**这一部分主要让模型学习 CSI 的规律，不需要人数或动作标签。**

**② 图2(b)：CSI Prediction——预测未来信号**

流程是：

**输入过去的 CSI → CSI-BERT2 → 输出未来的 CSI。**

它与(a)的关键区别是：

- **(a)：** 遮住序列中的随机位置，利用上下文恢复。

- **(b)：** 遮住序列末尾，根据前面的信号预测后面。

图右侧的基站、反馈箭头说明用途：提前预测信道变化，为通信系统优化提供依据。**这一部分预测的是信号，不是未来人数。**

**③ 图2(c)：CSI Classification——根据信号判断类别**

图中展示的是**画圈手势识别**：

**画圈时采集的 CSI → CSI-BERT2 → 输出“画圈”。**

上方两段 CSI 分别标着 **$m$ Hz、$n$ Hz**，表示采样率不同。作者想强调：**采样密度不同，同一个动作仍应识别成相同类别。**

人数估计也属于这一分支，只需把类别换成：

**CSI → CSI-BERT2 → 0人、1人、2人或3人。**

| **子图** | **模型最终输出什么** | **主要目的**               |
|----------|----------------------|----------------------------|
| **(a)**  | 被遮住位置的 CSI     | 学习信号规律、恢复缺失数据 |
| **(b)**  | 未来一段 CSI         | 预测信道变化               |
| **(c)**  | 动作、人数等类别     | 完成感知任务               |

**注意，这三个子图不是必须依次执行的三道工序。** 做人数估计时，是先通过(a)预训练，再训练(c)的人数分类头；不需要先经过(b)预测未来信号

| 数据集 | 来源 / 任务 |
|---|---|
| WiGesture | 实测；手势识别、人员身份识别及 CSI 预测 |
| WiFall | 实测；动作识别、跌倒检测及 CSI 预测 |
| WiCount | 实测；0—3 人的人数估计及 CSI 预测 |

论文比较恢复误差、预测误差、分类准确率及计算时间，并考察采样率变化和预训练、结构模块的消融。Table II 是网络配置；Table III 是数据集规模与任务概览，时长表示采集数据的总时间，不是一次预测要花多久。

Table IV 的恢复结果也说明优势不是每一列都成立：例如 WiCount 的 MSE，CSI-BERT2 为 2.4531，前作 CSI-BERT 为 2.4471。因此应分别看恢复、预测和分类，不能把某项任务的优势推广成“所有指标都最好”。

官方代码区分三种分类设置：100 Hz 训练 / 测试、100+50 Hz 混合训练 / 测试，以及 100 Hz 训练 / 50 Hz 测试。它们用于研究采样率适应，并不自动等价于跨房间、跨设备泛化。表格中的 Time 通常是整个测试集推理耗时，不是单个数据包延迟。

## 6. 总结与我的理解

这篇论文最值得学习的是“如何把同一套 CSI 表示用于多个任务”：标准化整理尺度，ARL 关注子载波差异，时间嵌入补充采集时间，掩码预训练提供无需人工类别标签的学习目标，再按任务微调。

**我的思考：** 较低的信号重建误差不必然带来更高分类准确率；恢复后的信号应继续用于下游任务检验。随机丢包、连续缺失和设备环境变化也应分别测试，不能只凭采样率实验就声称全面泛化。

## 7. 复现状态与后续问题

当前没有个人复现结果。可从官方 WiCount 人数分类开始，分别运行不预训练、预训练和不同采样率设置；随后对比有无 ARL、时间嵌入与 GAN 辅助训练。固定数据划分与随机种子，并分别记录各任务准确率、误差和单样本耗时。

## 8. 一句话总结

**CSI-BERT2 先通过掩码恢复学习 CSI 的规律，再结合子载波重加权和时间嵌入，用同一框架完成信号恢复、未来预测和感知分类。**
