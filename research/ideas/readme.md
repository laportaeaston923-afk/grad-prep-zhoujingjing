## Idea 01：面向接收机缺失的条件扩散 DFS 补全

- **记录日期：** 2026-10-19
- **状态：** 研究设想；尚未实现、训练或验证。
- **一句话概括：** 当部分 WiFi 接收机的数据缺失时，利用其余接收机的多普勒频谱（DFS）和接收机几何信息，生成缺失接收机的 DFS，再检查补全是否改善人体速度分布（BVP）恢复及手势识别。
- **研究问题：** 补全频谱的误差更小，是否真的意味着后续感知任务更准确？

## 1. 为什么从这个问题开始？

目前仓库已经有两部分基础：

1. [DDPM](../reproduction/01-ddpm-cifar10/) 与 [DDIM](../reproduction/02-ddim-cifar10/)：已开展噪声预测与采样实验，可以作为理解条件生成和采样加速的起点。
2. [Widar3.0：CSI → DFS → BVP](../reproduction/05-widar3-csi-dfs-bvp/)：已跑通一个样本的六接收机处理流程，可以观察频谱及 BVP 的变化。

因此，先在已有处理链中加入“缺失接收机补全”模块，比同时搭建新数据采集系统和大型生成模型更容易逐步验证。

**当前限制：** 仓库的 Widar3.0 结果仅覆盖一个示例，不能据此训练可靠的生成模型，也不能报告手势识别提升。正式实验需要另行准备多样本数据、标签和接收机几何信息，并核对使用许可。

## 2. 具体场景与任务边界

例如：原本有 6 个接收机，现在只收到其中 4 个接收机的数据，希望恢复另外 2 个接收机的 DFS。

本设想第一阶段研究的是**时间同步、固定几何配置下，整路接收机 DFS 缺失**。通过完整记录人为遮蔽部分接收机，构造可评估的输入与真值。

这与随机丢几个 CSI 数据包不同：整路缺失没有该接收机的有效输入，必须从其他视角推断。真实部署还可能包含时间不同步、噪声或设备异常，留到基础实验成立后再研究。

- **输入：** 可见接收机的 DFS、接收机可见性掩码、各接收机相对位置及朝向信息。
- **生成对象：** 缺失接收机的 DFS 时间片。
- **输出用途：** 与真实可见 DFS 拼接，送入已有 BVP 求解流程；后续再评估手势分类。
- **掩码作用：** 告诉模型哪些位置有真实观测、哪些位置需要补全，避免把零填充误当成有效频谱。
- **几何信息作用：** 不同接收机的径向速度投影不同，不能直接把一个接收机的频谱复制给另一个。

这里是条件信号补全任务；没有动作输入，也没有定义环境状态转移，暂不将其称为世界模型。

## 3. 最小方法设计

### 3.1 数据表示

将一个时间窗口内的 DFS 表示为 `X ∈ R^(R×F×T)`，其中 R 为接收机数、F 为频率格点数、T 为窗口长度。

先沿用当前流程的 DFS 频率定义，窗口长度由训练集时长与显存确定。所有实验采用相同预处理；明确频谱是幅值还是功率，并记录归一化和反归一化规则。

归一化统计只使用训练集；若使用逐样本统计，只能依赖实际可见输入，不能利用被遮蔽接收机的统计量。

### 3.2 条件扩散补全

1. 从完整训练记录中随机选择需要隐藏的接收机，得到掩码 M：可见为 1、缺失为 0。
2. 将可见频谱 `M⊙X`、M 和几何信息作为条件。
3. 对缺失区域的真实 DFS 加噪，使用小型条件 U-Net 预测噪声；主要噪声损失只在缺失区域计算。
4. 推理时从缺失区域的随机噪声开始去噪，生成缺失 DFS。
5. 最终拼接采用 `X_complete = M⊙X_observed + (1−M)⊙X_generated`，保留原始观测。

第一版只做基本条件 DDPM。训练完成后，可在相同权重下比较不同 DDIM 步数的质量与耗时；DDIM 加速不单独作为创新点。

频谱输出应满足所选表示的非负性要求。若使用对数变换，明确逆变换及数值截断方式。

### 3.3 第二阶段：跨接收机物理一致性

如果基础补全有效，再研究约束：**生成的多个接收机频谱，能否由同一个候选 BVP 按几何投影共同解释？**

可以沿用已有 BVP 与 DFS 的前向投影关系，先做离线一致性评估；若加入训练损失，需要另行实现并验证可微的投影或代理求解模块。现有 MATLAB 优化器不能直接当作可微网络反向传播。

一致性较好也不代表恢复出了唯一真实动作：有限视角可能对应多个合理解，仍需用被隐藏的真实 DFS 和下游任务评估。

## 4. 实验设计

### 4.1 必须先建立的对照

| 方法 | 用途 |
|---|---|
| 完整接收机观测 | 完整信息参考，不保证任何指标都构成严格数学上界 |
| 仅使用可见接收机求 BVP | 判断生成补全相对直接利用剩余数据是否有价值；需适配投影矩阵和接收机配置 |
| 缺失 DFS 零填充 | 最简单的缺失处理基线 |
| 确定性 CNN/U-Net 补全 | 判断是否需要扩散模型，而非普通回归即可解决 |
| 条件 DDPM 补全 | 验证生成式补全的效果 |
| 相同扩散权重的 DDIM 采样 | 比较采样步数、耗时与任务性能 |

网络补全方法应尽量使用相近规模的骨干、相同训练数据和一致的调参预算。

### 4.2 分阶段评估

| 阶段 | 实验 | 回答的问题 |
|---|---|---|
| A：流程验证 | 现有示例隐藏 1 路，检查掩码、窗口、拼接及 BVP 接口 | 处理链是否正确？此阶段不训练或宣称泛化 |
| B：同配置补全 | 多样本数据上分别隐藏 1、2、3 路；区分训练见过与未见过的接收机缺失组合 | 缺失加重时，补全是否仍有效？ |
| C：下游验证 | 固定 BVP 求解设置，比较完整、缺失及补全输入；有足够标签后训练分类器 | 频谱改善能否转化为感知收益？ |
| D：泛化验证 | 在数据支持时，分别留出用户或位置测试 | 模型是否只记住了特定用户或位置？ |

先按原始采集记录、会话或用户划分训练/验证/测试，再切窗口。同一记录的重叠窗口不能跨集合。几何配置若发生改变，需要单独设计实验，不能直接把固定配置结果解释成任意布局泛化。

### 4.3 指标与公平比较

- **频谱补全：** 在被隐藏区域计算 MAE、NMSE；注明在线性域还是变换域评估。
- **BVP：** 与同一条完整记录求出的 BVP 比较归一化分布距离及余弦相似度；完整观测 BVP 只是算法参考，不是真实人体速度标签。
- **手势识别：** 报告 Accuracy、Macro-F1，并固定分类器结构和数据划分。第一组对照可只用完整训练集训练同一个分类器，再比较不同测试输入的恢复效果。
- **计算成本：** 同一设备、批量和窗口长度下报告补全耗时、采样步数及包含预处理/BVP 求解的端到端耗时。
- **稳定性：** 报告多个随机种子或重复采样的均值和波动。

扩散模型可对同一输入生成多个结果，但主实验必须预先固定使用单次采样、样本均值或某种可部署的选择规则。不能借助被隐藏的真值挑选最好的生成结果，再作为实际效果报告。若展示 best-of-K，只能明确标为使用真值选择的诊断结果，并报告 K 及成本。

## 5. 消融与可能贡献

优先做三个消融：

1. **去掉几何条件：** 检查模型是否利用了接收机之间的几何关系。
2. **确定性回归 vs 扩散：** 检查多解建模是否值得额外采样成本。
3. **有无物理一致性约束：** 仅在第二阶段实现后比较，检查是否改善下游任务，而不只改善约束本身。

候选贡献是：围绕缺失接收机建立“DFS 补全 → BVP 恢复 → 识别”的可复现实验，并研究几何条件与跨接收机一致性对任务收益的影响。

**创新性尚未确认。** 把 DDPM 用于信号补全本身不足以证明新颖性。正式立项前，应检索多视角 WiFi 感知、缺失接收机恢复、条件扩散时序插补以及几何约束频谱补全的原始论文，逐项比较任务、条件、约束与评估协议。本文不声称首次提出该问题。

## 6. 执行顺序与停止条件

1. **准备数据：** 核对完整多接收机记录、同步、几何信息、标签和许可；保存按记录划分的清单。
2. **建立缺失基线：** 先完成可见接收机直接求解、零填充和确定性补全。
3. **实现条件 DDPM：** 先在固定配置、隐藏 1 路的设置验证，再扩展缺失程度。
4. **比较质量与成本：** 用 DDIM 改变采样步数，检查是否有可接受的性能与耗时折中。
5. **决定是否深化：** 只有基础补全对下游有稳定收益，再加入物理一致性约束。

若扩散只降低频谱误差，却不改善 BVP 或识别，需要分析任务相关信息是否被平滑或生成错误；若始终不优于确定性补全，应如实记录结果，并优先考虑更简单的方法。单个示例只用于调试，不能支撑研究结论。
