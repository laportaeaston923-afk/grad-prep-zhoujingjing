01 / 适合处理

小尺寸、压缩过的照片

尝试改善低分辨率照片的边缘与纹理。结果取决于图片内容和退化程度，保留原图再比较。

02 / 需要知道

新增细节，是模型的推测

严重失焦、运动模糊和完全丢失的信息不保证恢复。人脸特征、文字与物体纹理可能被改变。

03 / 不适合用途

别把生成纹理当作事实

证件文字、车牌和证据图片不应依靠生成结果判断。项目使用官方预训练模型，遵循非商业许可。

RUN ON YOUR OWN COMPUTER

本地推理，无需上传到第三方。建议使用 NVIDIA 显卡。
