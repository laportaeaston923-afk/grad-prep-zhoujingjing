如何读这些结果

  • 小数据、小网络的结果只能说明本次实现，不能据此判定哪篇论文更好。
  • DDPM/DDIM 共享权重，适合研究采样方式；像素 MLP 与 Tiny DiT 参数量不同，不是等预算架构实验。
  • VAE 的测试重建和随机生成分开评价；LDM 复用 VAE 的编码器与解码器。
  • Flow Matching 使用 Euler 积分；MeanFlow 实现平均速度恒等式与 JVP 训练，不是把普通流匹配直接改成一步。
  • 三个采样种子的标准差反映采样波动；所有网络只训练一次，不包含训练种子的方差。
  • 页面展示已训练模型的离线结果。重新训练、修改数据集和生成新种子，请运行仓库中的 Python 程序。
