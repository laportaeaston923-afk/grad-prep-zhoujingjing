01 / 真正的条件生成

只看剩余笔画，不偷看答案

U-Net 接收当前噪声图、可见像素和缺损掩码。被遮挡的参考像素不进入模型；参考图仅用于结果评估。

02 / 完整保留可见区域

只补缺损，不重画整张图

采样中按前向噪声调度约束已知区域，输出时逐像素保留可见部分。候选差异来自随机种子。

03 / 承认不确定性

“补得合理”不等于“找回原图”

严重遮挡可能存在多个解释。内置测试有原图可对照；上传已损坏的图时，请关闭参考评估。
